# Review Spec

## Your Mission

Read the current spec from `$ARTIFACTS_DIR/spec.md` and the user feedback below, then revise the spec to address every point.

## User Feedback

$LOOP_USER_INPUT

## Process

1. Read the full spec from `$ARTIFACTS_DIR/spec.md`
2. List each feedback point
3. Address each one explicitly — do not skip any
4. Rewrite the spec in full (do not leave sections unchanged with "same as before")
5. Note what changed and why

## Output

Write the revised spec to `$ARTIFACTS_DIR/spec.md` (overwrite the previous version).
