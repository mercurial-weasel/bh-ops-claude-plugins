# Review Plan

## Your Mission

Read the current plan from `$ARTIFACTS_DIR/plan.md` and the user feedback below, then revise the plan to address every point.

## User Feedback

$LOOP_USER_INPUT

## Process

1. Read the full plan from `$ARTIFACTS_DIR/plan.md`
2. List each feedback point
3. Address each one explicitly — do not skip any
4. Rewrite the plan in full (do not leave tasks unchanged with "same as before")
5. Note what changed and why

## Output

Write the revised plan to `$ARTIFACTS_DIR/plan.md` (overwrite the previous version).
